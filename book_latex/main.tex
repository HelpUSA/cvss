\chapter{Executive Summary}
This research monograph provides a comprehensive mathematical, architectural, and empirical reference for automated vulnerability prioritization under the FIRST Common Vulnerability Scoring System (CVSS) v4.0 specification. 

Addressing the operational limitations of using source CVSS assessments without organization-specific context, we introduce the HelpUS Framework: a system integrating network-topology evidence, an explainable evidence-constrained deterministic inference pipeline, specification-conformant CVSS v4.0 scoring, and a Human-in-the-Loop (HITL) review gate. The governance workflow is designed to support auditability and human oversight; it does not by itself establish compliance with NIST, ISO, PCI-DSS, or other frameworks. 

The 30-scenario Dataset B remains a development benchmark used for architectural verification and regression testing; it is not, by itself, evidence of external generalization. A pinned FIRST calculator reference corpus has been verified across all 486,472 test cases against official FIRST commit d766d0c8ab4368b67bf27dd0e411eb481f05fdbb with zero mismatches, closing the calculator conformance gate (G1). The later R6-A1 campaign added closed-world schema compatibility testing, historical and targeted mutation campaigns, downstream governance-contract verification, NVD representability analysis, differential comparison against cvss4py, and a preregistered held-out transfer evaluation over 938 GitHub Advisory Database records. In that transfer, 339 records were nominally calculable and 599 were rejected fail-closed without invented data; all 938 traces were verified across 3,232 diagnostic checks. These results strengthen engineering and transfer evidence while remaining distinct from the separately governed G10B/C1/C2 confirmatory protocol and from independent human expert adjudication, both of which remain future work. Engine-level timing measurements are reported separately from historical human-session timings and are not treated as a like-for-like end-to-end speedup. Web-layer audit-receipt canonicalization and authorization controls remain separate engineering claims that require their own conformance and security evidence.
