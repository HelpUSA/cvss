\begin{abstract}
Environmental metrics in the Common Vulnerability Scoring System (CVSS) allow
vulnerability severity to be contextualized to an organization's deployment
environment, but manual assessment is difficult to reproduce at scale. This
paper presents the HelpUS framework, an autonomous-by-default pipeline that
normalizes structured operational evidence, resolves environmental metric
candidates under deterministic policy rules, and delegates final CVSS v4.0
calculation to a deterministic FIRST-compatible scoring engine. The primary
study is non-human and evaluates normative conformance, reproducibility,
synthetic/metamorphic robustness, and a pre-registered held-out confirmatory
run. Human expert comparison is retained only as optional future work. An
optional HelpUS Cognitive Assurance Layer (HCAL) may provide secondary
semantic review, but it is non-blocking and cannot override the deterministic
score. The confirmatory C1/C2 run is governed by a single-pass blind protocol
with cryptographic custody, explicit authorization, and a no-retuning rule.
\end{abstract}
