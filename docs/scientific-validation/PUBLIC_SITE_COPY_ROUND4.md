# Public site scientific copy — Round 4

Apply equivalent wording in PT / EN / ES.

## Replace unsupported certainty

Do not use:

- `30 Cenários Validados` / `30 Validated Scenarios`;
- `sem/zero alucinações` as an absolute correctness guarantee;
- `100% correctness/agreement/traceability` unless the denominator and completed audit are shown;
- `Garantia de conformidade matemática`;
- `NVD Oficial` when the assessment may originate from a CNA;
- unqualified `RFC 8785 compliant`;
- `Contrato imutável` / `immutable proof`;
- `guaranteed compliance`;
- `validated noise reduction` for Dataset B.

## Preferred wording — Portuguese

- `Dataset B — benchmark de desenvolvimento (n=30)`
- `Usado para desenvolvimento, regressão e verificação arquitetural; validação independente C1/C2 ainda pendente.`
- `Avaliação CVSS de origem` instead of `NVD Oficial`.
- `Inferência determinística sob a mesma evidência, política e versão de regras.`
- `Estrutura de auditoria com evidência de adulteração (tamper-evident).`
- `Implementação de canonicalização compatível com JCS; validação formal RFC 8785 pendente.`
- `Revisão humana obrigatória quando a evidência é insuficiente, obsoleta ou conflitante.`

## Preferred wording — English

- `Dataset B — development benchmark (n=30)`
- `Used for development, regression, and architecture verification; independent C1/C2 validation remains pending.`
- `Source CVSS assessment` instead of `Official NVD`.
- `Deterministic given the same versioned evidence, policy, and ruleset.`
- `Tamper-evident audit structure.`
- `JCS-compatible canonicalization implementation; formal RFC 8785 validation pending.`

## Preferred wording — Spanish

- `Dataset B — benchmark de desarrollo (n=30)`
- `Usado para desarrollo, regresión y verificación arquitectónica; la validación independiente C1/C2 sigue pendiente.`
- `Evaluación CVSS de origen` instead of `NVD Oficial`.
- `Determinista con la misma evidencia, política y versión de reglas.`
- `Estructura de auditoría con evidencia de manipulación.`
- `Implementación de canonicalización compatible con JCS; validación formal RFC 8785 pendiente.`
