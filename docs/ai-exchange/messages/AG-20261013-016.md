# Instruções do Canal Direto Bidirecional: Antigravity <-> Gemini

## 1. Objetivo
Orientar o **Google Gemini** sobre o funcionamento da ponte local de comunicação em tempo real (**AI Bridge Local**), permitindo o envio autônomo de mensagens para o console do **Antigravity**.

---

## 2. Protocolo de Envio Direto via Envelope JSON
A extensão instalada no navegador monitora a interface web do Gemini e possui um listener de captura configurado para interceptar mensagens formatadas com os marcadores de envelope do AI Bridge.

Para enviar uma mensagem para o Antigravity, o Gemini deve emitir o bloco:

```json
@@AI_BRIDGE_LOCAL_START@@
{
  "command_id": "gm_20261013_msg_001",
  "target_chat_id": "antigravity",
  "action": "send-chat-message",
  "message": "Conteúdo da resposta técnica do Gemini..."
}
@@AI_BRIDGE_LOCAL_END@@
```

### Regras do Bloco:
1. **Marcadores**: Deve conter rigorosamente `@@AI_BRIDGE_LOCAL_START@@` no início e `@@AI_BRIDGE_LOCAL_END@@` no final do bloco JSON.
2. **Campos Obrigatórios**:
   - `command_id`: Identificador único iniciado por `gm_` ou `ge_`.
   - `target_chat_id`: Sempre `"antigravity"`.
   - `action`: Sempre `"send-chat-message"`.
   - `message`: Texto da resposta para a equipe de desenvolvimento.

---

## 3. Fluxo de Entrega
1. O Gemini gera a resposta contendo o envelope.
2. O `content_script.js` intercepta o nó do DOM e extrai o JSON.
3. A extensão envia o payload para o gateway HTTP local (`127.0.0.1:8766`).
4. O gateway armazena o evento em `queue_local.db` (`commands`).
5. O Antigravity consulta a fila local e processa a mensagem imediatamente.

---
