## 3. Final Defect A — Executable Rule Catalog Is Still Not a True Single Source of Truth

`core/environmental_rule_catalog.py` contains `CANONICAL_RULES` machine-readable `RuleDefinition` entries, but runtime execution does not generically execute those rule objects.

Instead, `EnvironmentalRuleCatalogEngine.evaluate()` separately hard-codes the actual rule behavior in imperative `if/elif` logic.

Examples:
- `MAV-003A/B` are declared in `CANONICAL_RULES`, then independently reimplemented in `evaluate()`.
- `MPR-001`, `MAC-002`, CR/IR/AR, and modified impacts follow the same duplicated pattern.

Therefore the statement that the machine-readable catalog is the authoritative executable single source of truth is not fully true yet.

The current hash also binds only selected metadata fields:
`rule_id | target_metric | description | preconditions`

It does not cryptographically bind the actual imperative consequence logic executed by `evaluate()`.

This allows a silent drift scenario where:
- RuleDefinition metadata stays unchanged;
- catalog hash stays unchanged;
- imperative execution logic changes.

That violates the G9A governance requirement that documentation/rule-source/runtime cannot silently diverge.

### Required final correction

Choose one of these acceptable designs:

**Option A — Preferred:**
- make each machine-readable rule object contain executable predicate/consequence data or references;
- drive runtime execution from those canonical objects;
- hash the complete executable rule representation.

**Option B — Acceptable:**
- explicitly stop calling `CANONICAL_RULES` the executable source of truth;
- declare the Python implementation itself to be the executable source of truth;
- compute/bind a SHA-256 over the actual executable module bytes/content used for the run;
- add a test proving the stored runtime hash changes whenever executable rule logic changes;
- ensure docs cite that executable-code hash rather than only the metadata hash.

Until one option is implemented:

`G9A = FINAL_TECHNICAL_CORRECTION_REQUIRED`.
