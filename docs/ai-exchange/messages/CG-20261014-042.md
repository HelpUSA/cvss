# CG-20261014-042
## FIRST-Aligned Guided UX + Removal of Stale Expert/HITL Operational Language

## Executive finding

The current product had too many purposes mixed on the same screens and the
publicly reachable production site still appears to expose an older, denser
frontend with stale AI/HITL/SuperAdmin-Master language.

This round restructures the canonical Next.js UX around a practical sequence:

`Login -> Organization -> Comece aqui -> Project -> Environment -> Assessment -> Evidence/Run -> Result/History`

The scientific deterministic baseline is not modified.

## Implemented by ChatGPT

### Public site

- Replaced the dense root dashboard with a concise landing page.
- Root now clearly separates:
  - public stateless demo;
  - authenticated operational workspace.
- Added direct FIRST User Guide and calculator links.
- Corrected language from "risk" toward CVSS severity/environmental context.
- Added FIRST attribution.

### Demo

- Public demo lives at `/demo`.
- Reduced it to the minimum fields required to understand the concept.
- Fixed the API payload to send `sourceAssessmentMeta`.
- Removed stale AI/HITL/expert framing.
- Demo remains stateless/non-tenant.

### Guided tenant flow

Added:

- `/app/[organizationSlug]/guide` — roadmap "Comece aqui";
- `/app/[organizationSlug]/assessments` — step 3 create/list;
- `/app/[organizationSlug]/assessments/[assessmentId]` — step 4 evidence/run;
- `/app/[organizationSlug]/assessments/[assessmentId]/runs/[runId]` — step 5 result.

Updated Projects and Environments pages to identify themselves as steps 1 and
2 and provide one explicit next action.

Updated the organization overview to compute and display the recommended next
step from real tenant counts.

### Assessment creation API

Added:

`POST /api/organizations/[organizationSlug]/assessments`

It requires an active session, tenant membership and `analysis:execute`, and
validates that the selected Environment belongs to the authenticated tenant.

### Result presentation

Added `web/src/lib/cvss-presentation.ts` to show FIRST nomenclature:

- CVSS-B
- CVSS-BT
- CVSS-BE
- CVSS-BTE

The result screen presents source score/vector separately from contextual
score/vector and preserves ABSTAIN semantics.

### Governance cleanup

- Removed mandatory-human-review semantics from the operational TypeScript
  analysis service.
- ABSTAIN now means evidence remediation is required, not mandatory human
  approval.
- Human review remains optional organizational policy, not a scoring
  requirement.
- Login text now says Google-only and no longer advertises alternate
  credentials/HITL governance.
- Reusable QuickStart/Methodology components no longer claim that AI agents or
  experts are mandatory runtime/scientific authorities.

### SEO / public boundary

- Authenticated `/app/`, `/api/`, login/reset/invitation routes are
  disallowed in robots.
- Sitemap now contains only public landing + demo.
- Metadata updated to CVSS environmental/severity terminology.

## FIRST UX model used

See:

`docs/architecture/FIRST_ALIGNED_GUIDED_UX.md`

The design follows FIRST concepts:

- separate Base/Threat/Environmental/Supplemental concepts;
- full human-readable names plus abbreviations;
- preserve vector;
- display score nomenclature;
- place contextual help near the question;
- link to User Guide/reference calculator;
- Base is severity, not complete organizational risk;
- consumer enriches vulnerability data with asset/environment data.
