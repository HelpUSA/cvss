## 3. Operational Implementation of HelpUS Cognitive Assurance Layer (HCAL)

Per the architectural specification in `CG-20261013-032` and `docs/OPTIONAL_AI_AUGMENTATION_ARCHITECTURE.md`, Antigravity implemented the complete HCAL runtime package under `core/ai_assurance/`:

1. **`core/ai_assurance/packages.py`**:
   - Versioned, hash-bound export packages: `VulnerabilityAnalysisPackage`, `EnvironmentReviewPackage`, `ExecutiveRiskPackage`.
   - `sanitize_data()`: Recursively strips credentials, passwords, tokens, API keys, and private keys, replacing them with `[REDACTED_SECRET]`.
   - `filter_allowlist()`: Enforces strict field allowlisting, discarding arbitrary or sensitive internal fields prior to transmission.
   - `PackageClassifier`: Computes canonical SHA-256 hash for every exported package payload.

2. **`core/ai_assurance/provider_adapter.py`**:
   - `AIProviderAdapter` (ABC): Abstract interface decoupling provider-neutral cognition from concrete models.
   - `DisabledProviderAdapter`: First-class no-op adapter ensuring Mode 0 (`CORE_AUTONOMOUS`) makes zero external or network calls.
   - `MockAIProviderAdapter`: Deterministic testing adapter supporting timeout simulation, fault injection, malformed responses, and custom findings.
   - `FindingItem` & `ProviderResponse`: Standardized return contracts distinguishing non-authoritative advisories from candidate facts.

3. **`core/ai_assurance/validation_firewall.py`**:
   - `HCALValidationFirewall`: Enforces all four non-negotiable architectural safety invariants:
     - `AI_DIRECT_SCORE_OVERRIDE = PROHIBITED`: Any attempt to alter CVSS scores or vectors directly is intercepted and logged as `REJECTED_DIRECT_SCORE`.
     - `AI_FINDINGS = ADVISORY_BY_DEFAULT`: Non-authoritative explanatory findings are admitted strictly as report annotations (`ADMITTED_ADVISORY`).
     - `AUTHORITATIVE_CANDIDATE_FINDINGS_REQUIRE_EVIDENCE_VALIDATION`: Candidate facts cannot modify metrics unless independently verified against structured evidence (`ADMITTED_VALIDATED_CANDIDATE`); unverified candidates are demoted to advisory warnings (`REJECTED_UNVERIFIED`).
     - Re-entry pathway: Admitted candidates update asset evidence, which is re-evaluated by the canonical `EnvironmentalRuleCatalogEngine` and scored deterministically by the FIRST engine.

4. **`core/ai_assurance/gateway.py`**:
   - `HCALGateway`: Orchestrates optional cognitive review across three operating modes:
     - `Mode 0 (CORE_AUTONOMOUS)`: Immediate return, `ai_enrichment_status = "SKIPPED"`, 0 ms latency, 100% deterministic CVSS execution.
     - `Mode 1 (SINGLE_AI)`: Single provider review with timeout circuit-breaker.
     - `Mode 2 (MULTI_AI)`: Multi-provider concurrent fan-out, `MultiAIComparisonMatrix`, and metric-level quorum enforcement (`STRICT_QUORUM_DELTA = 0`). Any provider divergence discards consensus updates and preserves baseline scores.
   - Graceful degradation: Provider timeout, network error, or complete outage sets `ai_enrichment_status = "NOT_AVAILABLE"`, never raising unhandled exceptions or blocking core scoring.
